# 訂單看板規格 🔧

## 長這樣

```
┌─ VEH-001 ──┐ ┌─ VEH-002 ──┐ ┌─ VEH-003 ──┐ ┌─ VEH-004 ──┐
│ 1  ORD-014 │ │ 1  ORD-003 │ │ 1  ORD-021 │ │ 1  ORD-008 │
│ 2  ORD-027 │ │ 2  ORD-011 │ │ 2  ORD-033 │ │ 2  ORD-019 │
│ 3  ORD-005 │ │ 3  ORD-101 │ │ 3  ORD-042 │ │ 3  ORD-044 │
│      ⋮     │ │      ⋮     │ │      ⋮     │ │      ⋮     │
│ 14 張       │ │ 12 張       │ │ 13 張       │ │ 11 張       │
│ 67.7/120kg │ │ 58.3/100kg │ │ 102/160kg  │ │ 90.4/110kg │
└────────────┘ └────────────┘ └────────────┘ └────────────┘

        [ 上一步 ]  [ 下一步 ]            [ 套用變更 ]
```

## 規則

1. 每欄只顯示 **站次 + 訂單編號**
2. **點一下訂單才展開**：配送時段、重量、預估到達、推薦理由
3. **上車前**：可跨欄拖（換車）、可同欄拖（換順序）、可刪除
4. **上車後**：只能同欄拖；跨欄會彈回並提示物理理由
5. **已發車**：已送達的站不能拖
6. 放開後**先試算再套用**，畫面顯示可不可以、代價多少
7. 不行要說原因：超重、跨出責任區、時段來不及、違反司機規則、已送達
8. **上一步 / 下一步**（undo / redo）
9. 數字**一律由後端算**，不准前端自己算一套
