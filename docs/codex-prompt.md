**五條最容易違反的規則：**

1. **全專案禁止用 regex 或關鍵字比對判斷語意。** 一律用 Agents SDK strict structured output，缺欄位就反問。驗收會用 8 種說法測同一個意圖，偷寫一定被抓到。
2. **LLM 不准算任何數字。** 重量、距離、載重率、ETA、違規判定全部由確定性程式算，模型只能引用工具結果。
3. **前端不准有空白 KPI 格**（「今日訂單 — 張」那種）。沒資料就不要畫那個區塊。
4. **只做規格 1.1 的六項功能**，想加東西先寫進 `TODO` 讓人類決定。
5. **方案卡長在對話裡**，是可點選的選項，不是獨立面板。每張都必須完全可行，差別只在代價。
