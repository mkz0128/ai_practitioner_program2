# 瀏覽器驗收清單

每完成一項 TODO，Codex 必須開瀏覽器實跑本檔對應的測項。**測不過不准寫進 `docs/progress.md` 的 `DONE`。**

## 通用規定

- 瀏覽器解析度 **1440 × 900**，全程開著 DevTools 的 Console 與 Network。
- 每個測項留截圖，檔名為測項編號，存於 `docs/screenshots/`。
- 「Console 乾淨」= 未處理的 error 與 page error 為 **0**。warning 可接受但要記錄。
- 每一輪測試結束都必須確認 **`/dispatch` requests = 0**、**`googleapis.com` requests = 0**。
- 失敗時貼上實際的錯誤訊息與截圖，不得只寫「失敗」。
- **不得因為「應該會過」而跳過測項。** 沒跑就是沒過。

| ID | 操作 | 預期 | 失敗判定 |
|---|---|---|---|

| E-09 | 掃全站圖示 | 沒有 `✦▣⌖` 這類 Unicode 符號當圖示 | 出現任一 |

## 判定與回報

每一輪測試在 `docs/progress.md` 的 `DONE` 用這個格式記錄：

```
- TODO N 完成 — 瀏覽器驗收：
  通過 XX/XX 項（E-01～E-09、F1-01～F1-15 …）
  失敗 0 項
  Console error 0、dispatch requests 0、googleapis requests 0
  截圖：docs/screenshots/F1-01.png 等
```

**有任何一項失敗就不准往下做。** 先修，修完重跑該區塊全部測項，再繼續。
