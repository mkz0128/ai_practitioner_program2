**這份是「上台會打什麼、Agent 必須回什麼」的唯一基準。**
驗收就是照這張表一句一句打，回不出來就是沒過。

狀態說明：
`✅ 我親自在瀏覽器驗過` / `🟨 有自動測試覆蓋，我沒親手打過` / `❌ 實測壞掉` / `⬜ 沒測過`

## 驗收方式

1. 開瀏覽器，**用鍵盤一句一句打**（不准用 API 直接打）
2. 一句一句對照上表的「必須回」
3. 每一句截圖存 `docs/screenshots/`，檔名就是本表的編號
4. **不准為了讓它過而修改本表的「你打」欄位**
